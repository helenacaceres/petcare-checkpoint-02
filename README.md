# PetCare API

Projeto desenvolvido para o Checkpoint 02 da disciplina Framework Application.

## Contextualização do projeto

O PetCare API é uma aplicação simples para cadastro de pets em uma clínica veterinária.  
O sistema permite cadastrar animais, listar todos os pets cadastrados, buscar um pet específico pelo ID e filtrar os pets por espécie.

O objetivo do projeto é demonstrar o uso de FastAPI no backend e HTML + JavaScript no frontend, utilizando requisições com fetch().

## Tecnologias utilizadas

- Python
- FastAPI
- Pydantic
- Uvicorn
- HTML
- JavaScript
- Fetch API
